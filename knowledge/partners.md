# Partner Track Notes

## fonio.ai

Teams build an empty-slot refill loop for appointment cancellations. The demo should show cancellation detection, candidate selection, an outbound call, and confirmed booking. Consent and edge cases matter.

## techbold

Teams build an AI-assisted technician workspace for Linux incidents. The system pulls tickets from a mock ERP, connects over SSH, diagnoses the issue, proposes actions, requires human approval, validates the fix, and writes an activity log.

## notarity

Teams simplify a complex notary appointment booking flow so a client can reach a valid booking in under 3 minutes. Country, product, participant, billing, shipping, consent, and conditional logic must be respected.

## HOIV Open Track

Teams build hands-free AI assistance for Meta Ray-Ban glasses using voice, vision, and agentic actions. Strong demos show real visual or audio input and useful output.

## HOIV Robo Dog

The HOIV Robo Dog track is listed as details coming soon. The bot should not invent unpublished requirements for this track.
