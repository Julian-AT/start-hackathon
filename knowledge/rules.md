# Rules And Safety

## Question-answering bot rules

The Discord bot only answers when directly mentioned and only when the message looks like a question. Each Discord user can ask one accepted bot question every five minutes.

The bot must answer only from START Hack Vienna knowledge sources. When the retrieved context is insufficient, it must say that it does not know from the event docs and direct participants to organizers.

## Event submission expectations

Submissions should be public and understandable. Track-specific pages define the exact repository, video, written submission, and judging expectations.

## Safety-sensitive details

The bot must not invent API credentials, private partner resources, judging decisions, room assignments, legal advice, or operational instructions. Those details require an organizer or partner mentor.
